# Star Network Topology Lab

## Objective
Create a star network topology using Cisco Packet Tracer and identify the OSI layers associated with the network devices and connections.

## Tools and Devices
- Cisco Packet Tracer
- Cisco 2960 Switch
- PT8200 Router
- PC and Laptop
- Server and Network Printer
- Ethernet cables

## Network Configuration
I connected all devices to a central switch and configured static IPv4 addresses in the 192.168.1.0/24 subnet.

## Testing
I used the ping command to verify communication between devices. The tested connections were successful with no packet loss.

## Challenges
I had difficulty establishing the connection between the router and the switch. I used Cisco IOS commands to check the interface status and reconnected the Ethernet cable.

## What I Learned
I learned how to build a star network topology, configure IP addresses, troubleshoot Ethernet connections, use basic Cisco IOS commands, and understand how OSI Layers 1, 2, and 3 work together.
